# Auris

Auris is an open-source personal music ecosystem designed to organize, manage and enjoy personal music libraries.

## About

Auris aims to combine the freedom of local music libraries with the convenience of modern music services.

The project focuses on giving users control over their own music collection while providing a modern and comfortable listening experience.

## Components

### Sonora
Android application for listening to music from the Auris ecosystem.

Planned features:
- Local music playback
- Music library management
- Album and artist organization
- Offline listening
- Smart cache system

### Auris Engine
Core technology behind the ecosystem.

Planned features:
- Audio format support
- Metadata processing
- Music library management
- Auris ID system

### Auris Desktop
Planned Windows/Linux application for managing large music collections.

## Vision

Create a modern music ecosystem where users own their library, but still have the convenience of modern streaming platforms.
